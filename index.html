Presentación del Proyecto

¿Qué es Jurictap? Es una plataforma digital para asesoría jurídica, gestión de citas, documentos y pagos.

Propósito: Facilitar el acceso a la justicia mediante herramientas tecnológicas seguras y fáciles de usar.

Problema que soluciona: La falta de un sistema accesible y organizado para personas de bajos recursos que necesitan orientación legal.

Componentes o Elementos

  • Frontend: HTML5, CSS3, JavaScript – interfaz visual.
  • Backend: Java – lógica de negocio.
  • Base de datos: MySQL – almacenamiento de usuarios, citas y documentos.
  • Roles: Cliente, Abogado, Pasante, Administrador.
  • Recursos: Computador, internet, navegador web.

Funcionamiento

El proyecto funciona de manera secuencial:

  1. Registro e inicio de sesión.
  2. Selección de rol.
  3. Acceso al panel correspondiente.
  4. Gestión de citas y documentos.
  5. Pagos y seguimiento de procesos.
  6. Valoración y verificación de asesores.

    Solución de Problemas

    Problema 1 - No puedo iniciar sesión

    El sistema rechaza las credenciales.

    1. Verifica que el correo y la contraseña estén escritos correctamente.
    2. Si olvidaste la contraseña, usa la opción Recuperar contraseña.
    3. Si el problema persiste, contacta soporte técnico.

    Problema 2 - No se guardan las citas

    El sistema no confirma la cita.

    1. Revisa que hayas seleccionado fecha y hora válidas.
    2. Confirma la cita con el botón Confirmar cita.
    3. Verifica en la sección Agenda si aparece registrada.

    Problema 3 - No se cargan documentos

    El archivo no aparece en la carpeta digital.

    1. Verifica que el archivo esté en formato permitido (PDF, DOCX, JPG).
    2. Usa el botón Subir documento.
    3. Confirma con Guardar y revisa en Ver documentos.

    Preguntas Frecuentes

    ¿Necesito pagar para usar Jurictap?

    El registro es gratuito. Algunos servicios especializados requieren pago.

    ¿Puedo acceder desde el celular?

    Sí, la plataforma funciona en cualquier dispositivo con navegador e internet.

    ¿Qué pasa si olvido mi contraseña?

    Usa la opción Recuperar contraseña en la pantalla de inicio de sesión.

    Conclusión

    ¿Qué herramienta digital utilizaron?

    Se utilizó HTML y CSS como herramienta digital principal, porque permite estructurar el manual en forma de página web clara, visual y accesible.

    ¿Por qué eligieron esa herramienta?

    La elegimos porque es sencilla de usar, se abre en cualquier computador con un navegador, no requiere programas costosos y facilita la integración de textos, diagramas e imágenes.

    ¿Cómo organizaron el manual?

    El manual se organizó en secciones: Portada, Presentación, Componentes, Funcionamiento, 12 módulos explicados, Solución de problemas, Preguntas frecuentes, Conclusión y Equipo de trabajo.

    ¿Cuál es el procedimiento principal de funcionamiento?

    El procedimiento principal es el registro e inicio de sesión, seguido de la gestión de citas y documentos legales, que son la base del sistema.

    ¿Qué parte del manual consideran más importante?

    La parte más importante es la de Funcionamiento y Módulos, porque explica paso a paso cómo usar Jurictap y permite a cualquier persona comprender y aprovechar la herramienta.
